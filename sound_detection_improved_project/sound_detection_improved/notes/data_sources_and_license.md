# گام دوم: تعیین منبع داده و بررسی مجوز
## پروژه تشخیص و طبقه‌بندی صدا (Sound Detection)

### ۱. هدف این مرحله
در این مرحله منبع داده‌های صوتی موردنیاز پروژه مشخص می‌شود و شرایط استفاده از آن‌ها از نظر مجوز بررسی می‌شود.

هدف پروژه، تشخیص و طبقه‌بندی صداهای محیطی از روی فایل صوتی است؛ مانند صدای حیوانات، باران، رعدوبرق، بوق خودرو، زنگ و صدای وسایل خانگی.

### ۲. منبع داده انتخاب‌شده: ESC-50
برای آموزش و ارزیابی اولیه مدل، مجموعه‌داده عمومی ESC-50 (Environmental Sound Classification) انتخاب شده است.

مشخصات مجموعه‌داده:
- تعداد نمونه‌ها: ۲۰۰۰ فایل صوتی
- تعداد کلاس‌ها: ۵۰ کلاس صوتی
- مدت هر فایل: ۵ ثانیه
- فرمت فایل‌ها: WAV
- نرخ نمونه‌برداری: ۴۴۱۰۰ هرتز
- تعداد بخش‌های ارزیابی: ۵ Fold

این مجموعه شامل صداهای حیوانات، طبیعت، صداهای انسانی غیرگفتاری، محیط داخلی و محیط شهری است.

### ۳. نشانی دریافت داده
مخزن اصلی:
https://github.com/karolpiczak/ESC-50

فایل دریافت مجموعه‌داده:
https://github.com/karolpiczak/ESC-50/archive/refs/heads/master.zip

مشخصات فنی:
https://audeering.github.io/datasets/datasets/esc-50.html

فایل esc50.csv نیز برای دریافت برچسب هر نمونه و اطلاعات تقسیم‌بندی داده‌ها استفاده می‌شود.

### ۴. بررسی مجوز استفاده
طبق توضیحات مخزن اصلی، مجوز مجموعه ESC-50 از نوع Creative Commons Attribution-NonCommercial 3.0 (CC BY-NC 3.0) است.

شرایط استفاده:
1. استفاده آموزشی و پژوهشی غیرتجاری با رعایت شرایط مجوز امکان‌پذیر است.
2. هنگام استفاده از داده‌ها باید به سازنده و منبع اصلی مجموعه‌داده ارجاع داده شود.
3. استفاده تجاری بدون کسب اجازه لازم مجاز فرض نمی‌شود.
4. فایل LICENSE مجموعه‌داده باید پیش از استفاده بررسی شود.
5. زیرمجموعه ESC-10 مجوز متفاوتی دارد و نباید شرایط آن را به کل ESC-50 تعمیم داد.

نتیجه بررسی: این مجموعه برای نمونه اولیه آموزشی و غیرتجاری پروژه مناسب است.

### ۵. روش دریافت و آماده‌سازی داده
1. دریافت مجموعه‌داده از مخزن اصلی ESC-50.
2. استخراج فایل‌ها در پوشه data/ESC-50.
3. نگهداری فایل‌های صوتی، فایل esc50.csv و اطلاعات مجوز.
4. بررسی فرمت، مدت و تعداد فایل‌های صوتی.
5. خواندن برچسب هر فایل از فایل CSV.
6. استفاده از Foldهای مشخص‌شده برای آموزش و ارزیابی مدل.
7. ثبت منبع و نسخه داده‌ها در مستندات پروژه.

### ۶. نحوه استفاده در پروژه
در نسخه اولیه، فایل صوتی به برنامه داده می‌شود. سپس فایل پردازش شده و ویژگی‌های صوتی آن برای مدل استخراج می‌شود.

خروجی مورد انتظار شامل:
- نام کلاس صوتی تشخیص‌داده‌شده
- میزان اطمینان مدل، در صورت پشتیبانی
- ثبت نتیجه تشخیص

### ۷. حریم خصوصی و ملاحظات اخلاقی
- در این مرحله از مجموعه‌داده عمومی استفاده می‌شود.
- صدای خصوصی افراد بدون رضایت آن‌ها وارد مجموعه داده نخواهد شد.
- در صورت ضبط صدا با میکروفون در مراحل بعد، رضایت افراد حاضر رعایت می‌شود.
- فایل‌های اصلی مجموعه‌داده بدون بررسی مجوز در مخزن عمومی GitHub بارگذاری نمی‌شوند.

### ۸. محدودیت‌ها
مجموعه ESC-50 فقط بخشی از صداهای محیطی را پوشش می‌دهد و ممکن است تمام شرایط واقعی ضبط، نویزها و صداهای موجود در محیط را شامل نشود.

بنابراین عملکرد مدل باید با داده‌های آزمایشی مناسب ارزیابی شود و نتایج آن به کلاس‌های موجود در مجموعه‌داده محدود خواهد بود.
