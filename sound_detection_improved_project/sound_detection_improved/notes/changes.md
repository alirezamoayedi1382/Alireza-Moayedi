# تغییرات اعمال‌شده نسبت به کد کلاسی

فایل‌های اصلی کلاس (`lab1_vacuum_agent.ipynb` و نسخه تکمیل‌شده) عامل جاروبرقی را در محیط چهار اتاق شبیه‌سازی می‌کنند. در نسخه پروژه، مسئله به تشخیص صدا تبدیل شده است.

- منطق حرکت بین اتاق‌ها و وضعیت کثیفی با بارگذاری فایل‌های صوتی و برچسب کلاس جایگزین شد.
- به کمک MFCC، ویژگی عددی از هر فایل صوتی استخراج می‌شود.
- مدل پایه Random Forest برای طبقه‌بندی اضافه شد.
- ارزیابی با Accuracy، Precision، Recall، F1-score و Confusion Matrix انجام می‌شود.
- مدیریت خطا برای فایل‌های خراب و کنترل نبود داده یا نمونه ناکافی اضافه شد.
- امکان پیش‌بینی کلاس یک فایل صوتی جدید پس از آموزش فراهم شد.

این تغییرات یک خط پایه آموزشی‌اند و نیازمند آزمایش روی داده‌های واقعی پروژه هستند.
