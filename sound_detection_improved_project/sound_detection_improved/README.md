# پروژه تشخیص صدا — نسخه بهبودیافته کد کلاسی

این نسخه با الهام از ساختار آزمایشگاه «عامل جاروبرقی» تهیه شده، اما مسئله اصلی آن به تشخیص و طبقه‌بندی صدا تغییر یافته است.

## اجرا
1. محیط Python 3.10 یا 3.11 را فعال کنید.
2. کتابخانه‌ها را نصب کنید:
   `python -m pip install numpy matplotlib librosa scikit-learn soundfile jupyter`
3. فایل `sound_detection_improved.ipynb` را در Jupyter Notebook یا VS Code باز کنید.
4. فایل‌های صوتی را در `data/train/نام_کلاس/` قرار دهید؛ فرمت‌های WAV، FLAC و OGG پشتیبانی می‌شوند.
5. سلول‌ها را به‌ترتیب اجرا کنید.

نمونه ساختار:
```text
data/train/
├── speech/
├── siren/
└── dog_bark/
```

حداقل دو کلاس و برای هر کلاس چند نمونه لازم است؛ برای تقسیم آموزش/آزمون طبقه‌بندی‌شده، دست‌کم دو نمونه در هر کلاس نیاز است، اما برای ارزیابی قابل اعتماد، داده‌های بیشتر توصیه می‌شود.

## فایل‌ها
- `sound_detection_improved.ipynb`: نسخه بهبودیافته آزمایش برای تشخیص صدا.
- `notes/changes.md`: خلاصه تغییرات نسبت به کد کلاسی.
- `notes/risks.md`: معیار ارزیابی و ریسک‌ها.
- `data/train/`: محل قرار دادن داده‌های صوتی.

## معیار ارزیابی
معیار پیشنهادی Macro F1-score است؛ نوت‌بوک Accuracy، گزارش Precision/Recall/F1 و ماتریس درهم‌ریختگی را نیز نمایش می‌دهد. تا قبل از اجرای مدل روی مجموعه‌داده مستقل، هیچ عددی نباید به‌عنوان عملکرد واقعی پروژه گزارش شود.
